# <span style="color:#FF5555">Device & Debugging</span>

### <span style="color:#50FA7B">ADB — Android Debug Bridge</span>

- **Purpose:** Command-line interface to communicate with an Android device/emulator.
- **Features:** Install APKs, execute shell commands, pull/push files, view logs, inspect processes and debug apps.

# <span style="color:#FF5555">Reverse Engineering</span>

### <span style="color:#50FA7B">**JADX — DEX to Java Decompiler**</span>

- **Purpose:** Decompile DEX bytecode and APK files back into readable Java/Kotlin source code.
- **Features:** GUI and CLI interfaces, easy navigation of decompiled code, extraction of embedded resources, and seamless integration with security auditing workflows.

### <span style="color:#50FA7B">**JADX-GUI — Graphical Android Decompiler**</span>

- **Purpose:** Provide a user-friendly graphical interface for decompiling DEX bytecode and APK files into readable Java/Kotlin source code.
- **Features:** Intuitive GUI with clickable code navigation, global text search across all decompiled classes, built-in resource viewer (AndroidManifest.xml, layouts, drawables), syntax highlighting, one-click export of all Java sources to a local folder, seamless integration with reverse engineering workflows, and support for obfuscated code deobfuscation.

### <span style="color:#50FA7B">**Apktool — Resource Decoder & Repackager**</span>

- **Purpose:** Decode APK resources to near-original form and repackage them after modifications.
- **Features:** Extract binary resources (XML, manifest, layouts), produce Smali bytecode (human-readable DEX), rebuild modified APKs, and resign/reinstall packages for behavioral testing.

# <span style="color:#FF5555">Emulators</span>

### <span style="color:#50FA7B">**Android Emulator (Google AVD)**</span>

- **Purpose:** Standard virtual device bundled with Android Studio for cross-version application testing.
- **Features:** Supports all API levels and Google Play Services, hardware acceleration (HAXM/Hyper-V), sensor simulation (GPS, camera, network), and deep IDE integration.

### <span style="color:#50FA7B">**Genymotion — High-Performance Android Emulator**</span>

- **Purpose:** Third-party emulator designed for developers and security professionals requiring speed and flexibility.
- **Features:** Faster cold boot and runtime performance, one-click root access, advanced sensor spoofing (GPS, battery, camera, accelerometer), cloud-based device options, and full ADB compatibility.

# <span style="color:#FF5555">Security Testing</span>

### <span style="color:#50FA7B">**MobSF (Mobile Security Framework)**</span>

- **Purpose:** All-in-one automated security testing framework for static and dynamic analysis.
- **Features:** Decompile APK and scan source code for vulnerabilities, perform runtime behavior analysis, generate comprehensive HTML/PDF reports with CVSS severity scoring, detect malware indicators, and identify insecure data storage practices.

### <span style="color:#50FA7B">**Drozer — Android Security Assessment Framework**</span>

- **Purpose:** Agent-based framework for deep-dive penetration testing targeting Android IPC components.
- **Features:** Interact with exported Activities, Services, Content Providers, and Broadcast Receivers; simulate malicious app behavior; test permission escalation and SQL injection risks; and extend functionality via custom modules.

### <span style="color:#50FA7B">**Yaazhini — Lightweight Vulnerability Scanner**</span>

- **Purpose:** Automated, user-friendly vulnerability scanner for Android APKs and REST APIs.
- **Features:** Quick static and dynamic analysis, detection of insecure storage, weak cryptography, SSL/TLS misconfigurations, hardcoded secrets, and generation of clear, actionable vulnerability reports.
