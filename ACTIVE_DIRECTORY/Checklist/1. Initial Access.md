# (Without Credentials / No Access)

### Anonymous / Guest Access 
#AD_anonymous_access 

- [ ] **SMB null session**
    - [ ] Enumerate accessible shares
- [ ] **RPC null session**
    - [ ] Enumerate usernames
- [ ] **LDAP anonymous bind**
    - [ ] Query base DN, users, groups, computers (`ldapsearch -x -H ldap://target -b "dc=domain,dc=local"`)
- [ ] **SNMP** (public/community strings)
    - [ ] Enumerate users

### User Discovery **(to build attack surface)**
#AD_user_enumeration 

- [ ] Perform **RID enumeration**
- [ ] **Extract usernames** from:
    - [ ]  If there is any website search and gather the usernames and passwords  (i.e content, comments, error messages, email addresses)
    - [ ] SMB shares (readable files with user lists)
    - [ ] LDAP (if anonymous bind works)
    - [ ] Generate a **custom username wordlist** (e.g., `first.last`, `flast`, `firstl`, etc.)
- [ ] Use **Kerbrute** for username enumeration
